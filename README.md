🛡️ GuardianSOS – AI Personal Safety App

GuardianSOS is a personal safety web application designed to help users during emergencies through SOS alerts, GPS location sharing, trusted contacts and quick access to emergency services.

🚀 Features

- 🆘 SOS Emergency Button
- 📍 Real-time GPS Location Access
- 👥 Trusted Emergency Contacts
- 📩 Emergency SMS Preparation
- 📞 Quick Emergency Call (112 – India)
- 📲 Location Sharing
- 🔒 Simple and User-Friendly Interface

💻 Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Geolocation API
- LocalStorage
- Web Share API

⚙️ Installation & Setup

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Install the Live Server extension.
4. Right-click "index.html".
5. Select Open with Live Server.
6. Allow location permission in your browser.

▶️ Run Locally

You can also run:

python -m http.server 8000

Open "http://localhost:8000" in your browser.

🎯 Project Objective

To make emergency communication easier by providing quick access to trusted contacts, GPS location sharing and emergency calling options.

⚠️ Disclaimer

GuardianSOS is a hackathon prototype, not a certified emergency-response service. SMS and sharing require user confirmation. Location access requires permission. In an immediate emergency in India, call 112 directly.
